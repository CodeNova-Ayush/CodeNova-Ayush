## `> cat ./projects.log`

<details>
<summary><b>🛡️ Clausr — Legal Risk Intelligence</b>&nbsp;&nbsp;<code>2025 · Active · Meta OpenEnv Finalist</code></summary>
<br/>

> *The first RL training system that teaches agents to simulate contract execution — not just read contracts, but run them like a flight simulator for legal risk.*

**What it does:**
- Finds hidden contradictions in legal contracts across 5 types — numeric, scope, party obligation, termination, definition
- Simulates business scenarios against contracts and finds the exact crash point
- Monitors negotiations clause by clause and fires the moment a contradiction is born

**Why it matters:**
- Grader is 100% deterministic — pure set intersection, no LLM, reproducible anywhere
- First multi-agent orchestration episode design in the OpenEnv catalog
- First incremental observation environment in OpenEnv history
- 0.85 mean baseline score with Mistral-small-latest

`Python` `FastAPI` `Pydantic v2` `React` `Vite` `D3.js` `Docker` `OpenEnv` `RL`

</details>

<details>
<summary><b>⚡ The Oracle — Contract Execution Simulator</b>&nbsp;&nbsp;<code>2025</code></summary>
<br/>

> *Feed it a business scenario. Watch it trace which clauses activate. Find the exact moment the contract enters an undefined legal state.*

- Multi-agent architecture: Scenario Generator + Execution Tracer in one episode
- Identifies crash points where two contradicting clauses fire simultaneously
- Shows financial exposure and which party is exposed at each crash
- First such design in the entire OpenEnv catalog

`Multi-Agent RL` `FastAPI` `Legal Intelligence` `OpenEnv`

</details>

<details>
<summary><b>🔍 LexMind — Negotiation Co-Pilot</b>&nbsp;&nbsp;<code>2025</code></summary>
<br/>

> *The agent doesn't get a finished document. It watches the contract being written — and fires the moment a contradiction is introduced.*

- First incremental observation environment in OpenEnv history
- Agent monitors clauses arriving one by one across negotiation rounds
- Institutional memory — recognizes patterns from past sessions
- Prevention, not autopsy

`Incremental RL` `OpenEnv` `FastAPI` `LegalAI`

</details>
