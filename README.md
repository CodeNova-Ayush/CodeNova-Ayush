## 💭 Dev Philosophy

> *"I don't wait for perfect conditions — I build, break, learn, and ship."*

| Principle | What It Means |
|:---------:|:-------------|
| 🔧 **Build** | Create systems that solve real problems, not toy projects |
| 💥 **Break** | Stress-test everything — if it can break, it will. Find it first. |
| 🔍 **Debug** | Root-cause analysis over quick fixes. Always. |
| 🚀 **Improve** | Every version should make the last one look like a draft |
| 🤖 **Automate** | If you do it twice, automate it the third time |
